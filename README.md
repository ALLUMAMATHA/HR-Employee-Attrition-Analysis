# HR Employee Attrition Analysis Dashboard

## Project Overview
This project focuses on analyzing employee attrition trends using Python and Power BI.  
The objective is to identify important factors affecting employee turnover and provide meaningful HR insights through data visualization and dashboard reporting.

The project includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Interactive Power BI Dashboard

---

# Objectives
- Analyze employee attrition patterns
- Identify departments with high attrition
- Study overtime impact on employee attrition
- Understand work-life balance trends
- Generate HR insights using data analytics

---

# Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI
- Excel / CSV Dataset

---

# Dataset Information
The dataset contains HR employee records including:
- Age
- Department
- Job Role
- Monthly Income
- Overtime
- Work Life Balance
- Years at Company
- Attrition Status
and other HR-related attributes.

---

# Project Workflow

## 1. Data Collection
Imported employee attrition dataset from CSV/Excel file.

## 2. Data Cleaning
- Removed unnecessary columns
- Checked missing values
- Cleaned dataset using Pandas
- Exported cleaned dataset

## 3. Exploratory Data Analysis (EDA)
Performed analysis on:
- Department-wise Attrition
- Overtime vs Attrition
- Work Life Balance Analysis
- Years at Company Analysis
- Job Role Analysis

## 4. Dashboard Creation
Created an interactive HR Analytics Dashboard using Power BI.

---

# Key Insights
- Employees working overtime show higher attrition rates.
- Research & Development department has the highest employee count.
- Sales Executives experience higher attrition.
- Employees with lower work-life balance are more likely to leave.
- Overall attrition rate is approximately 16%.
